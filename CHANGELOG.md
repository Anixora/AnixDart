# История изменений

## 1.0.1

- Исправлены типы моделей по AnixartJS и документации API: обязательные поля
  больше не nullable и требуют значения в конструкторе. `null` оставлен там,
  где он предусмотрен API или встречается в реальных ответах.
- Обновлены JSON-сериализаторы. Отсутствие обязательного поля или `null`
  вместо значения теперь приводит к ошибке декодирования.
- Сокращены повторяющиеся тесты, добавлены проверки обязательных полей.
  Проверки значений enum сохранены.
- Обновлены README и примеры, комментарии переведены на русский.

При обновлении проверьте ручное создание моделей: часть именованных
параметров конструктора теперь обязательна.

## 1.0.0

Первый публичный релиз.

- Перенесены 41 класс и 252 HTTP-метода AnixartJS: релизы, профили,
  авторизация, поиск, коллекции, статьи, уведомления, каналы, лента и остальные
  группы `src/api`.
- Добавлены модели запросов и ответов с `json_serializable`. Значения enum
  соответствуют API, поиск релизов поддерживает текущий и старый форматы ответа.
- Клиент работает на `package:http`, без зависимости от Flutter.
  Поддерживает JSON, формы, multipart, токен Anixart и Bearer-авторизацию.
- Через `RequestOptions` можно задать таймаут, отмену, версию API и обработку
  ошибок. Можно менять адрес сервера и передавать свои заголовки.
- Ошибки API доступны как `AnixartError`, ошибки HTTP и сети — как `HttpError`.
  Выбрасывание `AnixartError` можно отключить для отдельного запроса.
- Публичный импорт: `package:anixdart/anixdart.dart`.

Реализация сверена с AnixartJS и документацией API. Утилиты за пределами
`src/api`, в том числе парсеры видео/HLS, пока не перенесены. Неофициальный
API Anixart может измениться без предупреждения.
