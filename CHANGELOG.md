# Changelog

Все заметные изменения проекта будут публиковаться в этом файле.

## 1.0.0

Первый публичный релиз AnixDart.

### Добавлено

- Pure Dart-клиент для неофициального API Anixart без зависимости от Flutter.
- Перенесены 41 endpoint-класс и 252 публичных HTTP-метода из актуальной версии AnixartJS.
- Поддержаны основные разделы API:
  - релизы, эпизоды, история, избранное, расписание и видео;
  - профили, друзья, списки, настройки и роли;
  - авторизация и восстановление доступа;
  - поиск;
  - коллекции и комментарии;
  - статьи и комментарии;
  - уведомления;
  - каналы и лента;
  - config, discover, report, import, export и type.
- Типизированные модели запросов и ответов с `json_serializable`.
- Типизированные enum со значениями, соответствующими API Anixart.
- HTTP-транспорт на базе `package:http`.
- Поддержка JSON, `application/x-www-form-urlencoded` и `multipart/form-data` запросов.
- Поддержка Anixart token auth и Bearer auth.
- Поддержка `API-Version`, пользовательских заголовков и альтернативного base URL.
- `RequestOptions` для настройки timeout, отмены запроса, версии API и обработки ошибок.
- Отмена запросов через `RequestCancelToken`.
- Ошибки API представлены через `AnixartError`, HTTP/транспортные ошибки — через `HttpError`.
- Возможность отключить автоматическое исключение `AnixartError` для отдельного запроса через `throwOnAnixartError`.
- Поддержка текущего и legacy-формата поиска релизов.
- Публичная точка входа `package:anixdart/anixdart.dart`.

### Совместимость и ограничения

- Библиотека основана на актуальной архитектуре AnixartJS и сверена с неофициальной документацией Anixart API.
- Отдельные утилиты AnixartJS, не относящиеся к `src/api` (например, парсеры видео/HLS), пока не входят в AnixDart.
- API Anixart является неофициальным и может изменяться без предупреждения.
